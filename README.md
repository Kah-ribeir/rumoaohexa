Sistema de Gerenciamento da Copa do Mundo

Este projeto foi desenvolvido como trabalho acadêmico com o objetivo de aplicar os conceitos de Arquitetura MVC utilizando PHP e MySQL. O sistema simula o gerenciamento de uma Copa do Mundo, permitindo o controle de seleções, grupos, jogos, resultados e classificação.

A aplicação foi organizada seguindo o padrão MVC, separando a lógica do sistema (Controller), a comunicação com o banco de dados (Model) e a interface visual (View). Foram utilizados PHP, MySQL, HTML, CSS e XAMPP para o desenvolvimento.

O sistema permite listar seleções, organizar grupos, registrar jogos, inserir resultados e exibir a classificação. A interface foi estilizada com CSS, incluindo layout centralizado, fundo em degradê e tabelas com bordas personalizadas.

Durante o desenvolvimento, foram aplicados conhecimentos sobre estruturação de sistemas web, organização de código e integração com banco de dados.
