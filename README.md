#  Sistema de Gerenciamento da Copa do Mundo
Este projeto foi desenvolvido como trabalho acadêmico com o objetivo de aplicar os conceitos de arquitetura MVC (Model-View-Controller) utilizando PHP e MySQL.
O sistema simula o gerenciamento de uma Copa do Mundo, permitindo o controle completo de seleções, grupos, jogos, resultados e classificação.

##  Funcionalidades

-  Listagem de seleções
-  Organização por grupos
-  Cadastro de jogos
-  Registro de resultados
-  Exibição da classificação

## Tecnologias Utilizadas

- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Arquitetura

O sistema segue o padrão MVC:

- *Model* → responsável pela comunicação com o banco de dados  
- *View* → interface visual do sistema  
- *Controller* → lógica e controle das requisições  

## Interface
A interface foi estilizada com CSS, contendo:

- Fundo em degradê azul  
- Layout centralizado  
- Cards estilizados  
- Tabelas com bordas personalizadas e efeito hover
